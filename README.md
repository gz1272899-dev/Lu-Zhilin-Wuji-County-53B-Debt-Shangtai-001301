📊 模块二：尚太科技 (001301) IPO 原始股与资本运作疑云

资本市场维度的线索直指无极县本土A股上市公司——尚太科技（股票代码：001301）。

行政施压与原始股代持：
手段：利用土地审批、稀缺能耗指标拨付等行政审批权作为筹码。
异常定价：涉嫌通过隐秘的“白手套”，以仅 2元/股 的极低价格（远低于同期机构投资者的 10元/股）强行违规代持大量原始股。
巨额套现：尚太科技成功上市后，暗盘持有的股份被指悄然减持，涉案官员非法套现高达上亿元。
国有资产流失：作为利益交换，地方政府违规为该企业减免了 600余亩 工业用地的巨额土地出让金。
